# results/

This directory contains all output files produced by scripts.

## What is committed
- Small summary tables (`.csv`, `.json`)
- Final figures (`.png`)
- `data_audit.md` (checkpoint 1)
- `findings_summary.csv` and similar (checkpoints 6–10)

## What is gitignored
- `shots_processed.parquet` — the processed shot table (large, regenerated by scripts)
- `oof/` — out-of-fold prediction files (regenerated by scripts)
- Any `.pkl`, `.feather`, or `.parquet` files

## Directory layout (populated progressively)
```
results/
  data_audit.md          (checkpoint 1)
  shots_by_competition.csv  (checkpoint 1)
  figures/               (checkpoint 3+)
  ablation/              (checkpoint 6)
  calibration/           (checkpoint 7)
  transfer/              (checkpoint 8)
  oof/                   (gitignored; written by checkpoint 5 training)
```
